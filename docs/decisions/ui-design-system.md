# UI 디자인 시스템

## Decisions

- 메인 컬러는 파스텔 핑크(`--primary`), 민트 그린(`--secondary`), 크림 아이보리(`--background`) 톤을 기본으로 한다.
- 버튼, 카드, 대화창 등 주요 UI는 매우 둥근 형태(soft round)와 두꺼운 파스텔톤 테두리를 쓴다. `--radius`를 기존보다 크게(1.05rem) 잡아 전체 반경 스케일을 눌러 담는다.
- 화면 전반에 고양이 캐릭터 마스코트가 등장한다. 표정(neutral/happy/wink/crown)으로 문맥에 맞는 감정을 표현한다.
- 마스코트는 자체 제작 SVG(베지어 곡선 체형 + 그라데이션 + 소프트 드롭 섀도우, `CatMascot`)로 그린다. 톤(orange/white/gray) prop으로 배색을 바꿀 수 있다.
- 퀴즈 화면처럼 살아있는 느낌이 중요한 자리는 `@lottiefiles/dotlottie-react`로 LottieFiles의 무료 고양이 애니메이션(Lottie Simple License, 출처 표기 불필요)을 재생한다(`QuizCatMascot`). 평상시엔 눈을 깜빡이는 idle 애니메이션이 반복 재생되고, 정답/오답 선택 시 다른 애니메이션으로 잠깐 전환된 뒤 자동으로 idle로 돌아온다.
- 실시간 이미지 생성(AI) 서비스는 쓰지 않는다. 응답이 느리고(수 초 이상) 결과 이미지가 매번 손그림 같은 레퍼런스 톤과 어긋나, 사용자가 전면 중단을 요청했다(아래 참고).
- 개별 마스코트·버튼 같은 부품 단위 귀여움만으로는 레퍼런스의 인상을 재현할 수 없다. 화면은 항상 배경 장식(하늘 그라데이션, 구름, Stage 섬과 오솔길 같은 장면 요소)까지 포함한 하나의 구성으로 만든다. 부품만 나열한 컴포넌트 쇼케이스가 아니라, 화면 전체가 하나의 삽화처럼 보이도록 조합하는 것이 원칙이다.
- 보상 재화는 "츄"라는 고유 명칭과 발바닥 아이콘으로 표현한다.
- 주요 조작 버튼은 눌렀을 때 아래로 살짝 눌리는 두꺼운 하단 테두리(chunky press) 효과로 "쫀득한" 클릭감을 준다.

## Boundaries

- 이 스타일은 학생이 직접 보는 화면 전반(타이틀, Stage 목록, 퀴즈, 일시정지, 결과, 설정, 이후의 뽑기·도감·마이룸)에 적용한다.
- 화면별 구체적인 배치, 아이콘 선택, 마스코트 표정 조합 등 세부 디테일은 각 스펙/구현 시점에 자유롭게 정한다. 이 문서는 톤 앤 매너와 재사용 가능한 스타일 토큰만 규정한다.
- 다크 모드 전용 팔레트는 이번 결정에서 다루지 않았다. 필요해지면 별도로 정한다.
- 실시간 이미지 생성(AI) 서비스는 어떤 화면에도 쓰지 않는다.

## Why

사용자가 제공한 레퍼런스 목업(파스텔 핑크/민트/아이보리 배경의 고양이 캐릭터 테마 앱, 어휘 퀴즈·클리어 팝업·Stage 섬 지도 화면)을 근거로 확정했다. 사용자는 "픽셀 단위로 맞출 필요는 없고, 동글동글한 파스텔톤과 귀여운 캐릭터 분위기만 살리면 된다"며 세부 구현은 위임했다. `PRODUCT.md`의 "공부가 아니라 놀이처럼 느껴지는 인상"이라는 경험 원칙을 시각적으로 구현하는 결정이다.

## Reconsider when

- 실제 플레이 결과 아이가 이 톤을 좋아하지 않거나 산만하다고 느낄 때.
- 도감·마이룸처럼 꾸미기 콘텐츠 비중이 커지는 2차 스펙에서 지금의 토큰 구성이 부족하다고 판명될 때.
- 학교 네트워크에서 LottieFiles 도메인이 막혀 idle 애니메이션이 자주 안 뜰 때. `PRODUCT.md`가 원래 "서버 연동 없이" 로컬 우선을 전제로 했으므로, Lottie는 어디까지나 있으면 더 예쁜 장식이지 핵심 동작이 의존해선 안 된다.

## Still-rejected alternatives

- Twemoji(오픈소스 이모지 SVG) 기반 마스코트 — 배색을 테마에 맞게 바꿀 수 없고, 이모지 특유의 인상이 레퍼런스의 손그림 같은 귀여움과 달라 사용자가 되돌리길 원했다.
- Pollinations.ai 실시간 생성 이미지(결과 화면 히어로) — 로컬 개발 환경에서 이미지 하나를 받는 데 수 초가 걸렸고(Next 이미지 최적화까지 겹치면 6초 이상), 무엇보다 사용자가 "이미지 생성/AI 그림 작업은 전부 중단"을 명시적으로 요청해 되돌렸다. 완성도 있는 무료 캐릭터 일러스트 세트나 사용자가 직접 준비한 에셋이 생기면 다시 검토한다.

## Evidence worth preserving

- 레퍼런스 목업 3장(Stage 목록의 섬/오솔길 지도와 우측 둥근 사이드바 메뉴, 퀴즈 화면의 진행 중인 고양이 프로그레스 바와 말풍선 질문, 결과 화면의 왕관 쓴 고양이 축하 팝업과 "+10 츄!" 연출)을 사용자가 채팅으로 전달했다. 원본 이미지는 저장소에 없으므로, 재현이 필요하면 이 설명을 기준으로 다시 그린다.
- `app/design-preview`에 이 토큰과 컴포넌트를 조합한 확인용 화면이 있다. `PhoneFrame`(화면 프레임) + `SkyBackdrop`(하늘·구름 배경) + `StageIsland`(Stage 지도용 섬)로 타이틀·Stage 목록·퀴즈·일시정지·결과·설정 화면을 실제 장면처럼 나란히 구성해 뒀다. 퀴즈 화면에는 `QuizCatMascot`(Lottie idle/정답/오답) 데모 버튼이 있다.
