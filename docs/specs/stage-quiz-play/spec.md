# Stage 퀴즈 플레이 + 클리어

## 배경

`PRODUCT.md`가 정의한 핵심 루프(Stage 클리어 → 보상 재화 획득 → 캐릭터/아이템 뽑기 → 도감/마이룸)
중, 이번 스펙은 앞단인 "Stage를 플레이해서 클리어하고 포인트를 모으는" 부분만 다룬다.
뽑기, 도감, 마이룸 꾸미기는 이 스펙이 실제로 잘 동작하는 것을 확인한 뒤 별도 스펙으로 진행한다.

## 사용자에게 보이는 결과

- 학생은 Stage 목록에서 플레이할 Stage를 고를 수 있다.
- 학생은 고른 Stage에서 10문제(4지선다 객관식)를 순서대로 풀 수 있다.
- 오답을 골라도 감점이나 실패 없이 정답과 해설을 확인한 뒤 다음 문제로 넘어간다.
- 10문제를 모두 풀면 결과 화면에서 별점과 포인트 획득 연출을 본다.
- 클리어 결과(클리어 여부, 별점, 누적 포인트)는 앱을 껐다 켜도 유지된다.
- 이미 클리어한 Stage는 Stage 목록에서 클리어 표시(별점)로 구분되고, 다시 플레이할 수 있다.

## 승인된 범위

1. Stage 목록 화면 (Stage별 클리어 상태·별점 표시, 다음에 풀 수 있는 Stage 안내)
2. Stage 퀴즈 플레이 화면 (10문제, 4지선다, 오답 시 정답·해설 노출 후 진행)
3. Stage 결과 화면 (별점, 포인트 획득 연출)
4. 클리어 상태와 누적 포인트의 로컬 저장/복원
5. 일시정지 팝업 (이어하기 / 처음부터 다시 / Stage 목록으로 나가기). 나가면 해당 Stage 진행은 저장되지 않고 처음부터 다시 시작한다.
6. 설정 화면 중 "진행 상황 초기화"만. 소리(배경음악/효과음) 설정은 이번 범위에서 뺀다.

## 관찰 가능한 인수 기준

- Stage 목록에서 첫 Stage는 기본적으로 플레이 가능하고, 이후 Stage는 바로 앞 Stage를 클리어해야 플레이할 수 있다.
- Stage 진입 시 문제는 항상 10개이며, 정의된 순서대로 제시된다.
- 문제마다 4개의 보기 중 하나를 고르면 정답/오답 여부와 해설이 즉시 표시되고, 확인 후에만 다음 문제로 넘어간다.
- 오답을 골라도 Stage가 실패로 끝나지 않는다. 10문제를 다 풀면 항상 결과 화면에 도달한다.
- 결과 화면의 별점은 해당 플레이에서 맞힌 문제 수를 기준으로 정해진다: 9~10개 정답 = ★3, 6~8개 정답 = ★2, 0~5개 정답 = ★1. (최소 별 1개 보장, 실패로 인한 ★0은 없음)
- 결과 화면에는 이번 플레이로 획득한 포인트가 표시되고, 그 값만큼 누적 포인트가 증가한다.
- 브라우저를 새로고침하거나 앱을 재실행해도 각 Stage의 클리어 여부, 최고 별점, 누적 포인트는 그대로 유지된다.
- 이미 클리어한 Stage를 다시 플레이해서 완주하면, 별점은 이전 기록과 이번 결과 중 더 높은 값으로 갱신되지만 포인트는 다시 지급되지 않는다.
- 퀴즈 플레이 중 일시정지 팝업에서 "Stage 목록으로 나가기"를 고르면 해당 플레이는 저장되지 않고, 같은 Stage를 다시 시작하면 1번 문제부터 다시 시작한다.
- 설정 화면에서 "진행 상황 초기화"를 실행하면 모든 Stage의 클리어 상태·별점과 누적 포인트가 초기화되고, Stage 목록도 첫 Stage만 플레이 가능한 최초 상태로 돌아간다.

## 확정된 제약과 근거

- 문제 형식은 4지선다 객관식으로 한다. 채점 로직이 단순하고, 목숨 제한 없이 빠르게 다음 문제로 넘어가는 관대한 흐름과 맞는다.
- 오답에 실패나 페널티를 두지 않는다. `PRODUCT.md`의 "스트레스 없는 학습"이 최우선이라는 원칙을 그대로 따른다.
- 별점은 정답률에 연동하되 최소 1개를 보장한다. 실력에 따른 성취감은 주면서도, 오답에 대한 실패감은 주지 않기 위함이다.
- 포인트는 이번 스펙에서 실제로 로컬에 누적 저장한다. 2차 스펙(뽑기)이 이 값을 바로 사용할 수 있어야 하기 때문이다.
- 로그인이나 서버 연동은 하지 않는다. `PRODUCT.md`에서 이미 확정된 경계다.

## UI 디자인 가이드

전체 톤은 `docs/decisions/ui-design-system.md`(파스텔 핑크·민트·아이보리, 매우 둥근 형태, 고양이 마스코트)를 따른다. 이번 스펙의 세 화면에는 다음이 적용된다.

- Stage 목록 화면: 섬 또는 오솔길 형태의 타일 맵 위에 Stage 버튼을 배치하고, 우측에는 둥근 사이드바 메뉴를 둔다.
- 퀴즈 화면: 상단에 고양이 마스코트가 진행도를 따라 움직이는 진행 바를 두고, 문제는 말풍선 형태로 표시하며, 보기 버튼 옆에는 표정이 각기 다른 고양이 캐릭터를 배치한다.
- 결과 화면: 왕관을 쓴 고양이가 축하하는 팝업, 별점, "+n 츄!" 형태의 포인트 획득 연출을 보여준다.

세부 배치와 마스코트 표정 조합은 구현 시 자유롭게 정한다.

## 가정 (뒤집기 쉬운 선택, 필요 시 조정)

- Stage는 순차 잠금 해제 방식이다. 첫 Stage만 기본으로 열려 있고, 나머지는 바로 앞 Stage 클리어가 조건이다.
- 이미 클리어한 Stage는 몇 번이든 자유롭게 재도전할 수 있다.
- 재도전 시 포인트는 다시 지급하지 않는다. (별점만 최고 기록으로 갱신)
- Stage 안 10문제의 순서는 콘텐츠 데이터에 정의된 순서를 그대로 따르며, 매 플레이마다 무작위로 섞지 않는다.

## 범위 밖

- 보상 재화로 캐릭터·아이템을 뽑거나 해금하는 기능 (2차 스펙)
- 도감(컬렉션) 화면 (2차 스펙)
- 마이룸 꾸미기 (2차 스펙)
- 캐릭터 육성, 대전(PvP), 친구 비교, 리더보드 등 소셜·경쟁 요소 (`PRODUCT.md`에서 전면 배제)
- 로그인, 서버/DB 연동, 기기 간 진행 상황 동기화 (`PRODUCT.md`에서 전면 배제)

## 미룬 점

- 실제 중고생 필수 국어 어휘 데이터(전체 Stage 분량)는 아직 준비되어 있지 않다. 이번 스펙은 5 Stage(50단어) 분량의 샘플 데이터로 화면과 로직을 완성하고, 실제 전체 어휘 데이터는 이후 별도로 채워 넣는다. 콘텐츠가 늘어도 화면·로직이 그대로 동작해야 한다는 요건만 이번 스펙에 포함한다.

## 남은 위험

- 별점 구간(9~10/6~8/0~5)이나 재도전 시 포인트 미지급 규칙은 실제 플레이 후 아이가 느끼는 성취감과 다를 수 있다. 확정된 결정이지만, 실사용 확인 후 조정 여지가 있다.
- 샘플 데이터로 개발하므로, 실제 전체 어휘 데이터를 채울 때 Stage 수(50개 등 임의 가정)나 데이터 형식이 이번 구현과 맞지 않아 조정이 필요할 수 있다.
